# Interface design

The product follows Linear’s published approach to hierarchy and visual restraint: the working area takes priority, navigation recedes, actions occupy predictable places, and borders clarify structure with low contrast.

Use clear task names and ordinary sentence case. Avoid decorative eyebrows, slogans, redundant status lines and repeated explanations. Keep helper copy when it changes a user’s decision: missing inputs, storage state, errors and execution limits remain visible. Labels and controls must remain readable on mobile.

Use the Tye mark, charcoal surfaces and muted green action color. Functional icons remain vector assets. Starter illustrations use original generated raster artwork with print grain, cut-paper shapes and a small pastel palette inspired by the provided reference. Keep original source assets unchanged; serve optimized WebP files.

## Task illustrations

The current cards use revision 2 artwork: a framed landscape for image creation, a cinema filmstrip with successive bird poses for video creation, and a picture with a paintbrush and crop corners for editing. The print texture remains consistent, while each subject communicates its task. Prompts are recorded in [generated-artwork-v2.json](generated-artwork-v2.json). Original abstract artwork is preserved as the previous revision.
